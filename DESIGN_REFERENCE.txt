================================================================================

5. CARD DESIGN PATTERNS
================================================================================

  Standard Card:
    - border-radius: 0 (square corners by default)
    - box-shadow: 0 4px 15px rgba(0, 0, 0, 0.1)
    - hover shadow: 0 8px 25px rgba(0, 0, 0, 0.15)
    - hover transform: translateY(-8px)
    - transition: all 0.3s ease
    - image hover: scale(1.05) with 0.3s transition

  Overlay Card (Innovation, Services, Industries):
    - Height: 360px (desktop), 300px (tablet), 350px (mobile)
    - Gradient: linear-gradient(to bottom, rgba(0,0,0,0.1) 0%, rgba(0,0,0,0.7) 70%, rgba(0,0,0,0.9) 100%)
    - Overlay opacity: 0 -> 1 on hover (0.3s ease)
    - Title bar: position absolute, bottom: 0, background: #BF0603, padding: 15px 20px
    - On hover: title bar fades out, overlay with description fades in

  Testimonial Card:
    - border: 1px solid #BF0603
    - Star rating: filled #BF0603, empty #E0E0E0
    - Review text: italic
    - Title: red color (#BF0603)

  Achievement Card:
    - Aspect ratio: 1/1 (square)
    - Alternating colors:
      Light: bg #ECECEC, text #BF0603, border: 1px solid #BF0603
      Dark:  bg #BF0603, text #FFFFFF, border: none

10. SEO & META PATTERNS
================================================================================

  Required for every page:
    - <title> tag (unique per page)
    - meta description (unique per page)
    - canonical URL using useLocation()
    - robots meta tag
    - Open Graph tags (og:title, og:description, og:image, og:type, og:url, og:site_name)
    - Twitter Card tags (twitter:card, twitter:site, twitter:title, twitter:description, twitter:image)
    - viewport meta tag
    - charset UTF-8
    - Schema.org JSON-LD (Organization, WebPage, FAQ as applicable)

  Canonical URL Pattern:
    const location = useLocation();
    const canonicalUrl = `https://www.adiance.com${location.pathname}`;

  Twitter Handle: @adiancetech
  OG Site Name: Adiance Technologies


11. CSS NAMING CONVENTION
================================================================================

  Pattern: BEM-inspired with hyphens

    {component}-container     -> Main wrapper
    {component}-title         -> Heading
    {component}-description   -> Body text
    {component}-card          -> Card element
    {component}-header        -> Header section
    {component}-card-overlay  -> Hover overlay
    {component}-card-title-overlay -> Title bar on card

  Examples:
    .wwd-*            -> WhatWeDo section
    .blog-*           -> Blog section
    .testimonial-*    -> Testimonials section
    .achievement-*    -> Achievements section
    .industry-*       -> Industries section
    .service-*        -> Services section
    .innovation-*     -> Innovation section


12. IMAGE HANDLING
================================================================================

  - Use .webp format for all images (performance optimization)
  - Use object-fit: cover for consistent aspect ratios
  - overflow: hidden on image containers
  - Image hover: scale(1.05) with transition 0.3s ease
  - Always include descriptive alt text


13. BORDER RADIUS VALUES
================================================================================

  - Fully Rounded (dividers):  9999px
  - Buttons (minimal):         2px
  - Cards:                     0 (square corners default)


14. SHARED COMPONENTS

  Footer:  src/components/Footer/Footer

15. STYLE APPROACH
================================================================================

  - CSS-in-JSX (styled jsx) for component-scoped styles
  - Separate .css files for larger component styles
